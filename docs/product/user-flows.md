# User Flows

This document captures the main product flows at a high level. Detailed acceptance criteria should live in GitHub Issues/User Stories.

## Create and play a Game

1. A User chooses to create a Game.
2. The User selects a Game Mode.
3. Players are selected or added.
4. The Game may optionally be associated with a Playgroup.
5. The Game is created and started.
6. Players track Points during play.
7. The Game is ended when a winner is determined.
8. The Result is saved automatically.
9. The completed Game becomes available in relevant Game History and Statistics.

## Create or use a Playgroup

1. A User creates or joins a Playgroup.
2. The Playgroup contains a persistent list of Players/Users.
3. When creating a Game, the Playgroup can be selected as optional context.
4. Games associated with the Playgroup contribute to its history and statistics.

## Review history

1. A User opens their Game History or a Playgroup's Game History.
2. Completed Games are listed with their core Result information.
3. A Game can be opened to review its recorded details.

## Review statistics

1. A User opens Player or Playgroup Statistics.
2. The application aggregates completed Game Results.
3. Statistics are derived from stored Games rather than entered separately.
