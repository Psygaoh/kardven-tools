# Product Roadmap

This roadmap is intentionally high-level. GitHub Issues should contain the actual implementation work.

## Phase 1 — MVP

- User accounts.
- Create and start Games.
- Support `1V1`, `2V2`, `3playerFFA`, and `4playerFFA`.
- Add/select Players.
- Track Points during play.
- End Games and save Results.
- Basic Game History.
- Basic Player and Playgroup Statistics.

## Phase 2 — Playgroups and richer player context

- Improve Playgroup creation and membership flows.
- Better Playgroup history/statistics.
- Friend/player discovery and reusable player lists.
- Optional Deck/Legend tracking.

## Phase 3 — Competitive play

- Match support containing multiple Games.
- Competitive records and related statistics.
- Explore tournament-oriented features.

## Later possibilities

- Richer community features.
- Tournament management.
- Additional statistics and insights.
- Features driven by actual player usage and feedback.

The roadmap should evolve based on validated needs rather than attempting to reproduce every feature of other TCG tools.
