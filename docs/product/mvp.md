# MVP Scope

This document defines the first usable version of Kardven Tools. It should stay intentionally small and be updated as product decisions are validated.

## MVP goal

Allow players to quickly create and play a Riftbound Game with friends, track Points during play, and save the final Result automatically.

## In scope

- Registered Users.
- Creating a Game without requiring Playgroup membership or organizer approval.
- Adding/selecting Players for a Game.
- Supported Game Modes: `1V1`, `2V2`, `3playerFFA`, `4playerFFA`.
- Optional association of a Game with a Playgroup.
- Starting a Game.
- Tracking Points during the Game.
- Ending a Game and recording the Winner/Result.
- Game History for Players and Playgroups.
- Basic Statistics derived from completed Games.

## Optional metadata

- Deck identification, primarily through the deck's Legend.

Deck information should not block creating or playing a Game.

## Out of scope for the initial MVP

- Full decklists and card-by-card tracking.
- Detailed in-game actions beyond the Point total.
- Competitive Match structures containing multiple Games.
- Tournament management.
- Advanced community or organization administration.
- Any technical implementation choice not yet documented in the technical decisions.
